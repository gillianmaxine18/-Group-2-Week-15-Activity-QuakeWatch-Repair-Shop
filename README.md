# -Group-2-Week-15-Activity-QuakeWatch-Repair-Shop
Repair a broken data pipeline and prove that it works. Your group gets a copy of QuakeWatch, the earthquake pipeline, with six planted defects and 20 supplied tests. You find each defect, fix it, write it down, add tests of your own, and add proper logging. You use the Week 15 tools: pytest, a fake API, the debugger and the logging module.
